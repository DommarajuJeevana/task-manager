# Task Manager
A task management application that helps users organize, track, and manage daily tasks efficiently.

## Features
- User authentication
- Create tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Task status tracking
- Responsive UI

## Tech Stack

### Frontend
- React.js
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Clone Repository

git clone <repository-url>

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm run server

## Usage
- Register/Login
- Create new tasks
- Update task status
- Delete completed tasks
